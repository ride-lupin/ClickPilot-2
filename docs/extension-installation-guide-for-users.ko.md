# ClickPilot 확장프로그램 쉬운 설치 안내

이 문서는 개발자가 아닌 사용자가 ClickPilot 확장프로그램을 Chrome 또는 Edge에 설치하고 앱과 연결하는 방법을 설명합니다.

## 준비물

- ClickPilot 앱 설치 파일
- ClickPilot 확장프로그램 폴더
- Chrome 또는 Edge 브라우저

확장프로그램 폴더는 보통 `extension/dist`라는 이름입니다. 이 폴더 안에 `manifest.json` 파일이 보여야 합니다.

## 1. ClickPilot 앱 설치하기

1. 전달받은 ClickPilot 설치 파일을 엽니다.
2. 안내에 따라 ClickPilot 앱을 설치합니다.
3. 설치가 끝나면 ClickPilot 앱을 실행합니다.

## 2. Chrome에 확장프로그램 설치하기

Chrome을 사용하는 경우 아래 순서대로 진행합니다.

1. Chrome 주소창에 `chrome://extensions`를 입력하고 Enter를 누릅니다.
2. 오른쪽 위의 `개발자 모드` 스위치를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다` 버튼을 누릅니다.
4. 전달받은 확장프로그램 폴더에서 `extension/dist` 폴더를 선택합니다.
5. 목록에 `ClickPilot Button Picker`가 보이면 설치가 된 것입니다.
6. 주소창 오른쪽의 퍼즐 모양 아이콘을 누른 뒤 ClickPilot 아이콘을 고정합니다.

## 3. Edge에 확장프로그램 설치하기

Edge를 사용하는 경우 아래 순서대로 진행합니다.

1. Edge 주소창에 `edge://extensions`를 입력하고 Enter를 누릅니다.
2. `개발자 모드` 스위치를 켭니다.
3. `압축 풀린 항목 로드` 버튼을 누릅니다.
4. 전달받은 확장프로그램 폴더에서 `extension/dist` 폴더를 선택합니다.
5. 목록에 `ClickPilot Button Picker`가 보이면 설치가 된 것입니다.
6. 주소창 오른쪽의 퍼즐 모양 아이콘을 누른 뒤 ClickPilot 아이콘을 고정합니다.

## 4. ClickPilot 앱과 확장프로그램 연결하기

1. ClickPilot 앱을 엽니다.
2. 앱에서 `브라우저 버튼 선택` 또는 `토큰 갱신`을 누릅니다.
3. 앱 화면에 표시되는 `Port`와 `Pairing token`을 확인합니다.
4. 브라우저 오른쪽 위의 ClickPilot 확장프로그램 아이콘을 누릅니다.
5. `브릿지 포트`에는 `27183`을 입력합니다.
6. `Pairing token`에는 앱에 표시된 토큰을 그대로 입력합니다.
7. `연결 저장` 버튼을 누릅니다.
8. 확장프로그램 위쪽 배지가 `연결됨`으로 바뀌면 연결이 끝난 것입니다.

한 번 연결한 토큰은 만료되지 않습니다. 앱과 확장프로그램에 같은 토큰이 저장되어 있으면, 앱을 다시 켜도 연결 상태가 유지됩니다.

## 5. 연결 상태 배지 의미

- `연결됨`: 앱과 확장프로그램이 정상 연결된 상태입니다.
- `토큰 미등록`: 확장프로그램에 토큰을 아직 입력하지 않은 상태입니다.
- `앱 실행 필요`: ClickPilot 앱이 꺼져 있거나 연결할 수 없는 상태입니다.
- `토큰 확인 필요`: 앱의 토큰과 확장프로그램에 입력한 토큰이 다른 상태입니다.

## 6. 버튼 선택 테스트하기

1. 자동화하려는 사이트를 Chrome 또는 Edge에서 엽니다.
2. ClickPilot 앱에서 `브라우저 버튼 선택`을 누릅니다.
3. 브라우저 화면에서 자동화할 버튼을 클릭합니다.
4. ClickPilot 앱에 선택한 버튼 정보가 표시되면 정상입니다.

## 문제가 생겼을 때

- 확장프로그램이 설치되지 않으면 `extension/dist` 폴더를 선택했는지 확인합니다.
- `extension` 폴더 자체를 선택하면 설치가 안 될 수 있습니다. 반드시 그 안의 `dist` 폴더를 선택합니다.
- `앱 실행 필요`가 보이면 ClickPilot 앱을 먼저 실행합니다.
- `토큰 확인 필요`가 보이면 앱에서 새 토큰을 확인한 뒤 확장프로그램에 다시 입력하고 `연결 저장`을 누릅니다.
- 버튼 선택이 되지 않으면 브라우저 탭을 새로고침한 뒤 다시 시도합니다.
