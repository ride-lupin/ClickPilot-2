# ClickPilot 사용자 가이드

ClickPilot은 반복해서 처리하는 브라우저 업무를 정해진 시간에 자동으로 실행해 주는 프로그램입니다.

예를 들어 특정 사이트에서 `신청하기`, `예약하기`, `조회하기` 같은 버튼을 정해진 시간에 누르도록 저장할 수 있습니다.

## 1. 사용 전에 준비할 것

아래 항목이 준비되어 있어야 합니다.

- ClickPilot 앱
- Chrome 또는 Edge 브라우저
- ClickPilot 확장프로그램
- 자동화하려는 업무 사이트의 로그인 계정

확장프로그램 설치 방법은 `docs/extension-installation-guide-for-users.ko.md` 문서를 참고합니다.

## 2. 기본 사용 흐름

ClickPilot은 보통 아래 순서로 사용합니다.

1. ClickPilot 앱을 실행합니다.
2. Chrome 또는 Edge에서 자동화할 사이트를 엽니다.
3. 사이트에 미리 로그인합니다.
4. ClickPilot 앱과 확장프로그램이 연결되어 있는지 확인합니다.
5. ClickPilot에서 `새 작업`을 만듭니다.
6. 자동으로 누를 버튼을 `브라우저 버튼 선택`으로 저장합니다.
7. 실행할 날짜와 시간을 정합니다.
8. `저장`을 누릅니다.
9. 필요하면 `즉시 실행`으로 테스트합니다.

## 3. 확장프로그램 연결하기

ClickPilot이 브라우저 안의 버튼을 찾고 누르려면 앱과 확장프로그램이 연결되어 있어야 합니다.

1. ClickPilot 앱을 엽니다.
2. 화면의 `확장 프로그램 연결` 영역에서 `토큰 갱신`을 누릅니다.
3. 화면에 표시되는 `Port`와 `Pairing token`을 확인합니다.
4. Chrome 또는 Edge 오른쪽 위의 ClickPilot 확장프로그램 아이콘을 누릅니다.
5. 확장프로그램 화면에 `Port`와 `Pairing token`을 입력합니다.
6. `연결 저장`을 누릅니다.
7. ClickPilot 앱에서 `확장 프로그램 상태: 연결됨`으로 보이면 완료입니다.

한 번 연결한 토큰은 계속 사용할 수 있습니다. 앱을 껐다 켠 뒤에도 같은 토큰이면 다시 연결됩니다.

## 4. 새 작업 만들기

1. 왼쪽 메뉴에서 `새 작업`을 누릅니다.
2. `작업 이름`에 알아보기 쉬운 이름을 입력합니다.
   - 예: `오전 회의실 예약`
   - 예: `9시 신청 버튼 클릭`
3. `활성화`가 체크되어 있는지 확인합니다.
4. `실행 브라우저 방식`은 `기존에 열려 있는 브라우저 탭`을 사용합니다.

현재 버전에서는 `전용 자동화 브라우저`가 비활성화되어 있습니다. 따라서 자동화할 사이트는 사용자가 Chrome 또는 Edge에서 직접 열어 두어야 합니다.

## 5. 대상 탭 도메인 입력하기

`대상 탭 도메인`에는 자동화할 사이트 주소의 핵심 부분을 입력합니다.

예시는 아래와 같습니다.

- `ride-office.kr`
- `naver.com`
- `company.example.com`

정확한 전체 주소를 몰라도 괜찮습니다. 보통 주소창에서 회사나 서비스 이름이 들어간 부분을 입력하면 됩니다.

`현재 활성 탭만 사용`을 체크하면 현재 보고 있는 탭에서만 실행합니다. 여러 탭을 열어 두는 경우에는 체크하는 것이 안전합니다.

## 6. 자동으로 누를 버튼 선택하기

1. Chrome 또는 Edge에서 자동화할 사이트를 엽니다.
2. 사이트에 로그인합니다.
3. ClickPilot 앱에서 작업을 선택합니다.
4. `브라우저 버튼 선택`을 누릅니다.
5. 브라우저 화면으로 이동해 자동으로 누를 버튼을 한 번 클릭합니다.
6. ClickPilot의 `클릭 단계` 목록에 버튼 이름과 주소가 추가되면 성공입니다.
7. `저장`을 누릅니다.

여러 버튼을 차례대로 눌러야 한다면 `브라우저 버튼 선택`을 반복해서 누르고, 실제 사이트에서 버튼을 순서대로 선택합니다.

## 7. 새로고침 단계 추가하기

버튼을 누르기 전에 페이지를 새로고침해야 하는 업무라면 `새로고침 단계 추가`를 사용합니다.

예를 들어 아래처럼 구성할 수 있습니다.

1. `새로고침`
2. `예약하기` 버튼 클릭

이렇게 저장하면 실행할 때 먼저 현재 탭을 새로고침한 뒤 버튼을 누릅니다.

## 8. 스케줄 설정하기

`스케줄`에서 작업 실행 시간을 정합니다.

- `한 번`: 정해진 날짜와 시간에 한 번만 실행합니다.
- `매일`: 매일 같은 시간에 실행합니다.
- `매주`: 선택한 요일의 같은 시간에 실행합니다.
- `반복`: 정해진 간격으로 반복 실행합니다.

예약 실행은 ClickPilot 앱이 켜져 있을 때만 동작합니다. 예약 시간이 되기 전에 앱과 브라우저를 모두 켜 두고, 대상 사이트에 로그인해 둡니다.

## 9. 즉시 실행으로 테스트하기

작업을 저장한 뒤에는 먼저 테스트하는 것이 좋습니다.

1. 왼쪽 작업 목록에서 테스트할 작업을 찾습니다.
2. 작업 오른쪽의 실행 버튼을 누릅니다.
3. 화면에 `작업 실행을 시작했습니다.`가 보이는지 확인합니다.
4. 브라우저에서 원하는 버튼이 눌렸는지 확인합니다.
5. 오른쪽 `실행 로그`에서 성공 또는 실패 내용을 확인합니다.

테스트가 잘 되면 실제 예약 시간에도 같은 방식으로 실행됩니다.

## 10. 선착순 모드 사용하기

`선착순 모드`는 정해진 시간에 페이지를 새로고침한 뒤 버튼이 나타나는 순간 빠르게 클릭하는 기능입니다.

다음과 같은 업무에 사용할 수 있습니다.

- 예약 오픈 시간에 맞춰 `예약하기` 버튼 누르기
- 신청 시작 시간에 맞춰 `신청하기` 버튼 누르기
- 버튼이 늦게 나타나는 화면에서 버튼이 생기자마자 누르기

설정 방법은 아래와 같습니다.

1. 작업 편집 화면에서 `선착순 모드 사용`을 체크합니다.
2. `새로고침 방식`을 선택합니다.
   - `새로고침 안 함`: 현재 화면에서 버튼이 나타나기를 기다립니다.
   - `시작 시간에 1회 새로고침`: 예약 시간이 되면 한 번 새로고침한 뒤 버튼을 기다립니다.
3. `최대 대기 시간(ms)`을 입력합니다.
   - `10000`은 10초입니다.
   - `30000`은 30초입니다.
4. 필요하면 `텍스트 포함 조건`에 버튼에 들어갈 글자를 입력합니다.
   - 예: `신청`
   - 예: `예약`
5. `저장`을 누릅니다.

선착순 모드는 `기존에 열려 있는 브라우저 탭`에서만 사용할 수 있습니다.

## 11. 실행 로그 확인하기

오른쪽 `실행 로그`에서 작업 실행 결과를 확인할 수 있습니다.

로그에는 아래 내용이 표시됩니다.

- 작업 이름
- 실행 상태
- 시작 시간
- 완료 시간
- 실패 사유

자주 보이는 실패 사유는 아래와 같습니다.

- `버튼을 찾지 못했습니다`: 저장한 버튼이 현재 화면에 없거나 화면 구성이 바뀐 상태입니다.
- `로그인이 필요합니다`: 대상 사이트에서 로그인이 풀린 상태입니다.
- `브라우저를 찾지 못했습니다`: Chrome 또는 Edge가 실행되어 있지 않은 상태입니다.
- `대상 탭을 찾지 못했습니다`: 입력한 도메인과 일치하는 탭이 열려 있지 않은 상태입니다.

로그가 너무 많으면 `로그 전체 삭제`를 눌러 정리할 수 있습니다.

## 12. 작업 수정 또는 삭제하기

작업을 수정하려면 왼쪽 목록에서 작업 이름을 누릅니다.

수정 후에는 반드시 `저장`을 눌러야 합니다. 저장하지 않은 변경사항이 있으면 `현재 저장 안 됨`으로 표시됩니다.

작업을 삭제하려면 왼쪽 작업 목록에서 삭제 버튼을 누릅니다.

## 13. 실행 전 체크리스트

예약 시간이 가까워지면 아래 내용을 확인합니다.

- ClickPilot 앱이 켜져 있는지 확인합니다.
- Chrome 또는 Edge가 켜져 있는지 확인합니다.
- 자동화할 사이트 탭이 열려 있는지 확인합니다.
- 사이트에 로그인되어 있는지 확인합니다.
- ClickPilot 앱에서 `확장 프로그램 상태: 연결됨`으로 보이는지 확인합니다.
- 작업이 `활성화`되어 있는지 확인합니다.
- 대상 탭 도메인이 현재 사이트 주소와 맞는지 확인합니다.

## 14. 문제가 생겼을 때

버튼이 눌리지 않으면 아래 순서대로 확인합니다.

1. 브라우저에서 대상 사이트 탭이 열려 있는지 확인합니다.
2. 로그인이 풀렸다면 다시 로그인합니다.
3. ClickPilot 앱에서 확장프로그램 상태가 `연결됨`인지 확인합니다.
4. `대상 탭 도메인`이 실제 사이트 주소와 맞는지 확인합니다.
5. 사이트 화면이 바뀌었다면 `브라우저 버튼 선택`으로 버튼을 다시 저장합니다.
6. 작업을 다시 `저장`합니다.
7. `즉시 실행`으로 다시 테스트합니다.

## 15. 좋은 작업 이름 예시

나중에 헷갈리지 않도록 작업 이름에는 시간, 사이트, 업무 내용을 함께 적는 것이 좋습니다.

- `매일 09시 출근 체크`
- `월수금 10시 회의실 예약`
- `오전 9시 신청 버튼 클릭`
- `매일 18시 업무 마감 조회`

## 16. 주의사항

- ClickPilot 앱이 꺼져 있으면 예약 실행이 되지 않습니다.
- 브라우저가 꺼져 있으면 기존 탭 방식으로 실행할 수 없습니다.
- 사이트 로그인이 풀리면 버튼을 누를 수 없습니다.
- 사이트 화면이 바뀌면 저장된 버튼을 다시 선택해야 할 수 있습니다.
- 중요한 업무는 실제 예약 전에 `즉시 실행`으로 반드시 테스트합니다.
